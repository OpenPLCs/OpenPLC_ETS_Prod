# OpenKNXproducer

`OpenKNXproducer-x64.exe` is OpenKNXproducer v4.3.12 for Windows x64, unmodified, from the
[v4.3.12 release](https://github.com/OpenKNX/OpenKNXproducer/releases/tag/v4.3.12).
Source: <https://github.com/OpenKNX/OpenKNXproducer/tree/v4.3.12>
(commit `7f23a63ef641bb1c5501697af62d330181e3e23f`). Licence: GPL-3.0, in `LICENSE`.

SHA-256 of the exe: `b011c610a27f1264f26366670144cf59eca111fb2263df8c1d765696f82f8d59`

`tools/gen_product.py` runs it to sign the product with the local ETS 5.7. It creates
`Masters/` and `Temp/` next to itself at run time; they are not part of the repository.
